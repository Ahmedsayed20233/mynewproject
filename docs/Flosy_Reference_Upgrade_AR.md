# Flosy Studio — مرجع التصميم والمقارنة التنفيذية
**التاريخ:** 10 نوفمبر 2026 · **المرحلة:** تحسينات فعلية على تطبيق Flosy، وليس مجرد تصور.

## مصدر المقارنة
راجعنا أرشيفين ZIP أرسلهما صاحب المشروع، يحتوي الأول على 11 لقطة شاشة والثاني على 13 لقطة شاشة لتطبيقَي إدارة مالية على الهاتف. الصور للاطلاع والتقييم فقط، ولم ننسخها أو نرفعها إلى GitHub.

### المرجع الأول (ثيم داكن)
- Dashboard بمؤشر صرف شهري واتجاه مبسط.
- معاملات مصنفة بالتاريخ مع أوضاع Day / Week / Month / Year.
- اقتراح ميزانيات فئات مع قبول/تجاهل.
- زر إضافة مركزي وشاشة خيارات Expense / Income / Transfer / Budget.
- إدخال مبلغ، تاجر، تاريخ، وقت وفئة وملاحظة.
- تبويب Offers لكنه لم يعرض عروضًا متحققة في اللقطات.

### المرجع الثاني (واجهة بيضاء)
- حسابات وملخص نقدي وشاشة «Needs an answer / Get started».
- آخر معاملات مع هوية التاجر والتصنيف والوقت.
- تحليل Money in & out، وشاشة Wealth بقيم وحركة التاريخ.
- نافذة Ask لتفسير مصروفات المستخدم.
- اختصارات إضافة حساب، الصوت، الاستحقاقات، وتنظيم الأقسام.
- إعدادات مقسمة إلى الحسابات والتتبع والأمان والاستيراد والتصدير.

## ما كان موجودًا بالفعل في Flosy
1. **Flosy Elevate**: سجل يوم/أسبوع/شهر/سنة، اقتراح ميزانيات من شهور مكتملة، بطاقات قرارات مالية، وسجل لقطات حقيقي لصافي الثروة (بلا بيانات تاريخية مختلقة).
2. **Flosy Pearl**: White-only RTL، Safe to Spend، الاستحقاقات والتقويم، والمتابعة اليدوية للثروة.
3. **Flosy Capture**: صوت مصري + OCR وقواعد مراجعة SMS/CSV، مع تأكيد المستخدم قبل إضافة أي معاملة.
4. **Flosy AI Free**: تحليل محلي مجاني مبني على قواعد وأرقام المستخدم، وخيار OpenAI API منفصل.

## الإضافات المنفذة استنادًا إلى فجوات التجربة
| الفجوة | التنفيذ | ضمانة البيانات |
|---|---|---|
| الوصول السريع للإضافة | Flosy Studio launcher: مصروف/دخل/تحويل/ميزانية/صوت/إيصال | يستدعي **نموذج Flosy الأصلي** ولا يخلق سجلًا ثانيًا |
| الحسابات على الرئيسية | بطاقة أرصدة فعلية من دالة `FLOSY_PRO.rowsForAccounts` | تمييز أنها حسابات محلية/يدوية لا اتصال مباشر بالبنك |
| فرص التوفير | مثال توفير افتراضي 10% من أكبر فئة، أو تنبيه تجاوز سقف | «سيناريو» لا وعد بتوفير ولا عروض تجارية مزعومة |
| Money in & out | بطاقة آخر 30 يومًا مع دخل ومصروف وتحويلات | التحويلات منفصلة عن النفقات |
| تخصيص Widgets | عرض/إخفاء/ترتيب 4 بطاقات رئيسية | تفضيلات `state.studio` فقط دون تعديل معاملات |
| إعدادات يصعب اكتشافها | اختصارات الحسابات والقواعد والاستيراد والخصوصية | استخدام الصفحات الحالية بدل إعدادات مكررة |
| تجربة الهاتف | Bottom sheet، أهداف لمس أكبر، RTL، تباين واضح | White mode فقط |

## أمور لم نضفها عمدًا
- عروض تجارية من مؤسسات لم تتعاون معنا: لا توجد شراكات أو بيانات عروض موثقة.
- حساب تاريخ ثروة وهمي؛ نستخدم لقطات المستخدم الحقيقية فقط.
- اتصال تلقائي بالحسابات البنكية/Thndr أو سحب الأموال.
- نقل لغة أو شعارات أو أيقونات أو أصول البرامج المرجعية حرفيًا.
- مطالبة المستخدم بتسجيل الدخول أو دفع اشتراك لاستخدام أدوات حسابية محلية.

## معايير قبول الإصدار
- نجاح Node/CI في حسابات المال، سلامة الكاش، الخصوصية، والواجهات.
- نجاح Chromium E2E: اختيار تخصيص بطاقة وحفظه، فتح Quick Add من الويب والهاتف، تحويل بين حسابين لا ينشئ مصروفًا، OCR لا يحفظ بدون موافقة.
- لا أخطاء JavaScript عند تشغيل التطبيق بدون بيانات؛ لا اعتماد جديد على API مدفوع.
- توافق بصري في شاشة 390px ومراقبة أي overflow.
- الاختبار الفعلي للكاميرا/الميكروفون ومزامنة أجهزة Android يظل خطوة قبول مستقلة ولا يحل محلها Chromium.

## البنية
- `flosy-elevate.js/css`: صفحات الميزانية والمعاملات والثروة (موجودة مسبقًا).
- `flosy-studio.js/css`: Quick Add، بطاقات الحسابات وفرص التوفير، تفضيلات الترتيب، واختصارات الإعدادات.
- `index.html`: نقاط دمج الواجهات + خطاف إعادة الرسم.
- `service-worker.js`: ترقية ذرية للملفات في وضع عدم الاتصال.
- `tests/v4.test.cjs` و`tests/browser-smoke.cjs`: انضباط النتائج المالية واختبارات واجهة فعلية.
