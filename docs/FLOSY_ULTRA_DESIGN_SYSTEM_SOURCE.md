## 1. فلسفة التصميم وتجربة المستخدم (UI/UX Core Philosophy)

1. **الثقة المالية والهدوء البصري (Emerald & Obsidian FinTech Psychology):**
   - استبدال الألوان النيون المجهدة للعين بنظام ألوان مستوحى من البنوك الرقمية العالمية: **الكحلي الأوبسيديان العميق (`#0B1324`)** للخلفيات، مع **الأخضر الزمردي (`#10B981`)** للنمو والأمان، و**الذهبي الشامبانيا (`#F59E0B`)** للثروة والادخار.
2. **قاعدة الـ 3 ثوانٍ (3-Second Clarity Rule):**
   - بمجرد فتح التطبيق، يعرف العميل خلال 3 ثوانٍ بالضبط: كم يتبقى له للصرف بأمان (`8,250 ج.م`)، وكم يمكنه صرفه اليوم (`458 ج.م / يوم`).
3. **إدخال المعاملات بدون مجهود (Zero-Friction Input):**
   - توفير 3 طرق للإدخال (إدخال يدوي بلمسة واحدة عبر أزرار `+50` و`+100`، مسح الفاتورة بالكاميرا `OCR`، أو التحدث الصوتي `Voice AI`).
4. **الأرقام الجدولية المتناسقة (Tabular Numerals):**
   - جميع الأرصدة والمبالغ تستخدم خاصية `font-variant-numeric: tabular-nums` بحيث تتساوى خانات الأرقام عمودياً تحت بعضها لسهولة المقارنة السريعة.

## 8. المؤثرات الحركية والتفاعلية (Micro-Interactions & Animations)

1. **نبض الميكروفون الصوتي (`pulseSonic`):**
   ```css
   @keyframes pulseSonic {
     0%   { transform: scale(0.92); opacity: 0.75; }
     50%  { transform: scale(1.16); opacity: 0.25; }
     100% { transform: scale(0.92); opacity: 0.75; }
   }
   /* المدة: 2.2s infinite ease-in-out */
   ```
2. **حركة ليزر مسح الفاتورة (`laserSweep`):**
   ```css
   @keyframes laserSweep {
     0%   { top: 8%;  opacity: 0.9; }
     50%  { top: 84%; opacity: 1.0; }
     100% { top: 8%;  opacity: 0.9; }
   }
   /* المدة: 2.5s infinite ease-in-out */
   ```
3. **تأثير إخفاء الأرصدة للخصوصية (`Privacy Blur`):**
   ```css
   .privacy-blur {
     filter: blur(7px);
     user-select: none;
     transition: filter 0.25s ease;
   }
   ```
4. **استجابة الأزرار عند اللمس (`Touch Feedback`):**
   - عند التحويم (`Hover`): `transform: scale(1.01)` أو `scale(1.02)`
   - عند الضغط (`Active/Tap`): `transform: scale(0.95)` مع انتقال سريع `transition: all 0.2s cubic-bezier(0.16, 1, 0.3, 1)`
